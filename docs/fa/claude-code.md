# Claude Code از طریق کلیدیفای

[English](../claude-code.md)

Claude Code با هر چیزی حرف می‌زند که `ANTHROPIC_BASE_URL` به آن اشاره کند، و
این کار را با Anthropic Messages API انجام می‌دهد. دروازهٔ کلیدیفای به همان API
پاسخ می‌دهد، پس Claude Code روی کیف پول ریالی شما اجرا می‌شود، بدون وصله زدن به
آن و بدون پراکسی شخصی.

مرجع کامل دستورها همراه خود بسته است، که منبع درست محسوب می‌شود و با خود ابزار
نسخه می‌خورد:
**[`@kilidify/claude` در npm](https://www.npmjs.com/package/@kilidify/claude)**.
این صفحه مسیر کوتاه است به‌علاوهٔ چیزهایی که مردم روی آن‌ها گیر می‌کنند.

## نصب و اجرا

```bash
npm install -g @anthropic-ai/claude-code @kilidify/claude

kilidify login     # کلید kl_live_… خود را وارد کنید
kilidify           # Claude Code از طریق کلیدیفای اجرا می‌شود
```

هر چیزی که به `claude` می‌دادید اینجا هم کار می‌کند:

```bash
kilidify -p "این مخزن را توضیح بده"
kilidify -- --model opus         # هر چه بعد از -- بیاید بدون تغییر به claude می‌رسد
```

## دائمی کردن تنظیم

```bash
kilidify setup              # ~/.claude/settings.json، برای همهٔ پروژه‌ها
kilidify setup --project    # .claude/settings.local.json، فقط همین پروژه
kilidify setup --mcp        # سرور MCP را هم ثبت می‌کند
kilidify setup --undo       # آنچه setup نوشته را برمی‌دارد
```

بعد از `setup`، خود `claude` هم از کلیدیفای عبور می‌کند. این دستور در فایل
تنظیمات موجود ادغام می‌شود، بقیهٔ تنظیم‌ها را دست‌نخورده نگه می‌دارد و پیش از
نوشتن، نسخهٔ پشتیبانی کنار آن می‌گذارد.

**پیش از اجرای `setup` بسته را سراسری نصب کنید.** این دستور یک `apiKeyHelper`
تنظیم می‌کند که `kilidify key` را صدا می‌زند، پس اگر آن دستور در حافظهٔ موقت
`npx` باشد، با پاک شدن آن حافظه کار نمی‌کند. نشانه‌اش این است که Claude Code
گزارش می‌دهد اسکریپت `apiKeyHelper` شما شکست می‌خورد.

این واسط برای آن است که کلید در فایل تنظیمات خود کلیدیفای بماند، با دسترسی
`0600` و فقط برای مالک، به جای اینکه در تنظیمات Claude Code نوشته شود. اگر
ترجیح می‌دهید کلید مستقیم در فایل باشد، `setup --plain-key` همین کار را
می‌کند.

## اینکه Claude موجودی شما را ببیند

```bash
kilidify setup --mcp
```

این دستور سرور MCP را ثبت می‌کند که `kelid_balance`، `kelid_exchange_rate`،
`kelid_search_models` و `kelid_estimate_cost` را در اختیار می‌گذارد، پس خود
Claude می‌تواند وسط کار به «این چقدر خرج برمی‌دارد» و «موجودی من چقدر است»
پاسخ بدهد. سرور در هر فراخوانی کلید ذخیره‌شده را دوباره می‌خواند، پس یک
`kilidify login` تازه بدون راه‌اندازی دوبارهٔ Claude Code اثر می‌کند.

## بررسی تنظیمات

```bash
kilidify status     # در دسترس بودن دروازه، اعتبار کلید، موجودی به دلار و تومان، نرخ روز
kilidify models     # مدل‌های Claude با قیمت هر یک میلیون توکن به هر دو ارز
```

ردیف آخر همان است که بی‌جهت مردم را نگران می‌کند: بعضی امکانات جانبی خود Claude
Code صرف‌نظر از `ANTHROPIC_BASE_URL` به Anthropic وصل می‌شوند و از ایران آن
تماس‌ها شکست می‌خورند. درخواست‌های واقعی شما تحت تأثیر نیستند.
`kilidify config set nonessential on` ترافیکی را که بیرون از دروازه می‌رود
خاموش می‌کند.

## چطور کار می‌کند

Claude Code درخواست‌های Anthropic Messages را به `ANTHROPIC_BASE_URL`
می‌فرستد. کلیدیفای آن‌ها را روی `/v1/messages` می‌پذیرد، کلید و سقف درخواست و
کیف پول را بررسی می‌کند، درخواست را با کلید بالادستیِ سقف‌دارِ خودتان به بالا
می‌فرستد، پاسخ را مستقیم جریانی برمی‌گرداند، و از روی تعداد توکن و هزینه‌ای که
ارائه‌دهنده گزارش می‌کند از کیف پول شما حساب می‌کند.

چون شکل خطا برای منطق تلاش دوبارهٔ Claude Code اهمیت دارد، کلیدیفای برای
درخواست‌های با شکل Anthropic خطای هم‌شکل برمی‌گرداند و خطاهای بالادستی را بایت
به بایت عبور می‌دهد. [`errors.md`](errors.md) را ببینید.

## بدون بستهٔ کلیدیفای

این بسته یک راحتی است، نه یک الزام. کل سازوکار دو متغیر محیطی است:

```bash
export ANTHROPIC_BASE_URL=https://api.kilidify.com
export ANTHROPIC_AUTH_TOKEN=kl_live_…
claude
```

به این شکل نام‌های کوتاه مدل‌ها مثل `opus` و `sonnet` به شناسهٔ مدل‌های کلیدیفای
تبدیل نمی‌شوند، پس مدل را کامل نام ببرید، برای نمونه
`claude --model anthropic/claude-sonnet-5.5`. بیشترِ چیزی که بسته اضافه می‌کند
همین نقشهٔ نام‌هاست.
