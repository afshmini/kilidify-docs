# خطاها

[English](../errors.md)

پیش از جدول، دو قاعده ارزش دانستن دارند.

**خطاهای خود کلیدیفای به شکل کتابخانهٔ شما درمی‌آیند؛ خطاهای بالادستی نه.**
درخواستی که در خود دروازه شکست بخورد (کلید نادرست، نبود موجودی، مدل غیرمجاز،
سقف درخواست) به همان شکلی برمی‌گردد که کتابخانهٔ شما انتظار دارد. درخواستی که
به ارائه‌دهنده رسیده و آنجا شکست خورده، بایت به بایت عبور داده می‌شود، چون
کتابخانه‌ها بر اساس متن خود بالادستی تصمیم می‌گیرند. به‌خصوص Claude Code از روی
متن خطای بالادستی تصمیم می‌گیرد که تلاش دوباره بکند یا نه، پس بازنویسی آن متن
تلاش دوباره را بی‌صدا از کار می‌اندازد.

**هر خطای دروازه یک پیام فارسی همراه دارد.** `message_fa` کنار `message`
می‌نشیند، تا بشود دلیل واقعی را بدون یک مرحله ترجمهٔ دیگر به کاربر فارسی‌زبان
نشان داد.

## دو شکل خطا

اینکه کدام یک را می‌گیرید به خود درخواست بستگی دارد، نه به یک تنظیم. درخواستی
Anthropic شمرده می‌شود که مسیرش با `/v1/messages` شروع شود یا هدر
`anthropic-version` داشته باشد. بقیه شکل OpenAI می‌گیرند.

شکل OpenAI:

```json
{
  "error": {
    "code": "insufficient_balance",
    "message": "Insufficient balance. Top up your wallet to continue.",
    "message_fa": "موجودی کیف پول شما کافی نیست. لطفاً حساب خود را شارژ کنید.",
    "type": "insufficient_quota"
  }
}
```

شکل Anthropic، برای همان وضعیت:

```json
{
  "type": "error",
  "error": {
    "type": "billing_error",
    "code": "insufficient_balance",
    "message": "Insufficient balance. Top up your wallet to continue.",
    "message_fa": "موجودی کیف پول شما کافی نیست. لطفاً حساب خود را شارژ کنید."
  }
}
```

مقدار `code` در هر دو یکی است و همان فیلدی است که باید بر اساسش شاخه بزنید.
`type` فرق می‌کند چون هر اکوسیستم دسته‌های خود را جور دیگری نام می‌گذارد؛ در
شکل Anthropic از روی وضعیت HTTP ساخته می‌شود (401 می‌شود
`authentication_error`، 402 می‌شود `billing_error`، و همین‌طور).

## همهٔ کدها

### احراز هویت، 401

<div dir="rtl">

| کد | معنی | راه‌حل |
| --- | --- | --- |
| `no_api_key` | درخواست هیچ کلیدی ندارد. | `Authorization: Bearer kl_live_…` یا `x-api-key` بفرستید. |
| `invalid_api_key` | چنین کلیدی وجود ندارد. | احتمال کپی ناقص را بررسی کنید. کلیدها فقط یک بار هنگام ساخت نمایش داده می‌شوند. |
| `key_revoked` | کلید باطل شده است. | در پنل کلید تازه‌ای بسازید. |
| `key_expired` | تاریخ انقضای کلید گذشته است. | کلید تازه‌ای بسازید، یا در پنل تمدیدش کنید. |

</div>

### پرداخت و سهمیه، 402

این‌ها یعنی درخواست فهمیده شده و به دلیل پول رد شده است، نه به دلیل شکل. چیزی
حساب نشده است.

<div dir="rtl">

| کد | معنی | راه‌حل |
| --- | --- | --- |
| `not_provisioned` | حساب هنوز دسترسی بالادستی ندارد. | اعتبار اضافه کنید؛ دسترسی با رسیدن اولین پرداخت فراهم می‌شود. |
| `insufficient_balance` | کیف پول کفاف این درخواست را نمی‌دهد. | شارژ کنید. موجودی پیش از ارسال بررسی می‌شود، پس هرگز زیر صفر نمی‌روید. |
| `budget_exceeded` | همین کلید به بودجهٔ ماهانهٔ خودش رسیده، هرچند کیف پول پول دارد. | بودجهٔ کلید را در پنل بالا ببرید یا بردارید، یا از کلید دیگری استفاده کنید. |
| `trial_tokens_exhausted` | سهمیهٔ دورهٔ آزمایشی رایگان تمام شده است. | برای ادامه شارژ کنید. |

</div>

### دسترسی، 403

<div dir="rtl">

| کد | معنی | راه‌حل |
| --- | --- | --- |
| `account_suspended` | حساب معلق شده است. | در پنل تیکت پشتیبانی باز کنید. |
| `model_not_allowed` | این کلید اجازهٔ استفاده از مدل خواسته‌شده را ندارد. | مدل‌های مجاز کلید را ببینید. `GET /v1/models` با همان کلید دقیقاً می‌گوید چه چیزی مجاز است. کلید آزمایشی به چند مدل ارزان محدود است. |

</div>

### درخواست، 400 / 408 / 413

<div dir="rtl">

| کد | وضعیت | معنی |
| --- | --- | --- |
| `invalid_body` | 400 | بدنهٔ درخواست قابل تجزیه نبود. |
| `auto_not_configured` | 400 | `kilidify/auto` روی کلیدی خواسته شده که نقشهٔ نقش ندارد. در پنل برای هر نقش مدلی انتخاب کنید، یا مدل را مستقیم نام ببرید. |
| `request_timeout` | 408 | بدنهٔ درخواست به‌موقع نرسید. |
| `payload_too_large` | 413 | بدنهٔ درخواست از اندازهٔ پذیرفته‌شده بزرگ‌تر است. |

</div>

### سقف درخواست، 429

<div dir="rtl">

| کد | معنی | راه‌حل |
| --- | --- | --- |
| `rate_limit_exceeded` | سقف درخواست در دقیقهٔ همین کلید. | کمی صبر کنید و دوباره بفرستید. سقف برای هر کلید جداست و در `GET /v1/credits` با نام `rate_limit_rpm` دیده می‌شود. |
| `concurrency_limit_exceeded` | تعداد درخواست‌های هم‌زمان در جریان برای این حساب زیاد است. | وقتی یکی تمام شد دوباره بفرستید. این شمارش درخواست‌های هم‌زمان است نه یک نرخ، پس کل راه‌حل همان کمی صبر کردن است. |

</div>

### بالادستی و داخلی، 500 / 502 / 504

<div dir="rtl">

| کد | وضعیت | معنی |
| --- | --- | --- |
| `internal_error` | 500 | خطایی از سمت ما. تلاش دوباره بی‌خطر است. |
| `upstream_unavailable` | 502 | ارائه‌دهنده در دسترس نیست. |
| `upstream_timeout` | 504 | ارائه‌دهنده درخواست را پذیرفت و به‌موقع پاسخ نداد. |

</div>

یک 502 یا 504 ارزش دارد که یکی دو بار با مکث کوتاه دوباره فرستاده شود. اگر یک
مدل به طور مداوم در دسترس نیست در حالی که بقیه سالم‌اند، معمولاً مسئله ظرفیت
بالادستی است نه چیزی مربوط به حساب شما.

## مدیریت خطاها در کد

بر اساس `code` شاخه بزنید، هرگز بر اساس `message`. پیام‌ها برای آدم‌ها نوشته
شده‌اند و ترجمه می‌شوند؛ قرارداد واقعی کدهاست.

```python
from openai import OpenAI, APIStatusError

client = OpenAI(base_url="https://api.kilidify.com/v1", api_key=key)

try:
    reply = client.chat.completions.create(model=model, messages=messages)
except APIStatusError as error:
    code = (error.response.json().get("error") or {}).get("code")

    if code in ("insufficient_balance", "trial_tokens_exhausted"):
        ...   # به کاربر بگویید شارژ کند؛ تلاش دوباره کمکی نمی‌کند
    elif code == "budget_exceeded":
        ...   # سقف همین کلید پر شده؛ ممکن است کیف پول هنوز پول داشته باشد
    elif code == "model_not_allowed":
        ...   # مدلی از فهرست مجاز انتخاب کنید
    elif code in ("rate_limit_exceeded", "concurrency_limit_exceeded"):
        ...   # کمی صبر کنید و دوباره بفرستید
    elif code in ("upstream_unavailable", "upstream_timeout", "internal_error"):
        ...   # با مکث فزاینده دوباره بفرستید
    else:
        raise
```

سه دسته‌ای که در عمل اهمیت دارند: **402 با تلاش دوباره هرگز موفق نمی‌شود**،
**429 سرانجام موفق می‌شود**، و **5xx معمولاً موفق می‌شود.** اگر همهٔ شکست‌ها را
قابل تلاش دوباره بدانید، کیف پول خالی به حلقه‌ای تنگ روی سرویسی تبدیل می‌شود که
قرار است همچنان رد کند.
