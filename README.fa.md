کلیدیفای یک دروازهٔ API است. با یک کلید و یک آدرس پایه به مدل‌های Anthropic،
OpenAI، Google، Meta، DeepSeek، Mistral، Z.ai و Qwen دسترسی دارید و حساب خود را
با درگاه‌های بانکی ایرانی و به ریال شارژ می‌کنید. به کارت بین‌المللی و حساب
بانکی خارجی نیازی نیست.

کلیدیفای اکانت اشتراکی نمی‌فروشد: کلید، موجودی و گزارش مصرف شما از خودتان است و
هزینه بر اساس توکن مصرفی محاسبه می‌شود. مدلی هم آموزش نمی‌دهیم و میزبانی
نمی‌کنیم؛ ظرفیت را از سرویس‌های بالادستی می‌خریم و لایهٔ پرداخت، حسابداری و
محدودیت‌های هر کلید از ماست.

## شروع سریع

آدرس پایه `https://api.kilidify.com/v1` است. هر کتابخانهٔ سازگار با OpenAI را به
آن وصل کنید و کلید را عوض کنید. هیچ چیز دیگری در کد شما تغییر نمی‌کند.

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.kilidify.com/v1",
    api_key="kl_live_…",            # از https://kilidify.com/api-keys
)

reply = client.chat.completions.create(
    model="anthropic/claude-sonnet-5.5",
    messages=[{"role": "user", "content": "سلام!"}],
    stream=True,
)

for chunk in reply:
    print(chunk.choices[0].delta.content or "", end="")
```

نمونه‌های اجراشدنی با curl، پایتون، Node و SDK رسمی Anthropic در
[`examples/`](examples/) هستند.

## دو شکل API، نه یکی

بیشتر دروازه‌ها فقط یک درگاه سازگار با OpenAI می‌دهند. کلیدیفای علاوه بر آن به
**Anthropic Messages API** هم پاسخ می‌دهد، بنابراین SDK رسمی Anthropic و
Claude Code بدون واسطه کار می‌کنند.

| درخواست شما | پاسخ کلیدیفای |
| --- | --- |
| `POST /v1/chat/completions` | شکل OpenAI |
| `POST /v1/messages` یا هر درخواست با هدر `anthropic-version` | شکل Anthropic |

خطاها هم از همین قاعده پیروی می‌کنند و این مهم‌تر از آن است که به نظر می‌رسد:
Claude Code تلاش مجدد خود را بر اساس متن خطای بالادستی تصمیم می‌گیرد، پس
دروازه‌ای که شکل خطا را اشتباه برگرداند، این منطق را بی‌صدا از کار می‌اندازد.

## Claude Code با پرداخت ریالی

```bash
npm install -g @anthropic-ai/claude-code @kilidify/claude

kilidify login     # کلید kl_live_… خود را وارد کنید
kilidify           # Claude Code از طریق کلیدیفای اجرا می‌شود
```

دستور `kilidify setup` این تنظیم را دائمی می‌کند تا از آن پس خود `claude` هم از
کلیدیفای عبور کند. کلید در فایل تنظیمات خود کلیدیفای با دسترسی `0600` می‌ماند و
از طریق `apiKeyHelper` خوانده می‌شود، نه در فایل تنظیمات Claude Code.

راهنمای کامل: [`docs/claude-code.md`](docs/claude-code.md)

## چطور کار می‌کند

| | |
| --- | --- |
| **رابط** | سازگار با OpenAI و با Anthropic Messages. چت، پاسخ جریانی، فهرست مدل‌ها و بقیهٔ مسیرهای بالادستی که بدون تغییر عبور داده می‌شوند. |
| **پرداخت** | شارژ به ریال از طریق درگاه‌های بانکی ایرانی. اطلاعات کارت در صفحهٔ خود بانک وارد می‌شود و هیچ‌گاه به کلیدیفای نمی‌رسد. |
| **محاسبهٔ هزینه** | بر اساس توکن مصرفی، با تعرفهٔ همان مدل به‌علاوهٔ کارمزد سرویس. موجودی کیف پول به دلار نگه داشته می‌شود و نرخ از بازار آزاد و هر پنج دقیقه به‌روز می‌شود. نرخ هر شارژ روی همان تراکنش ثبت می‌ماند و بعداً تغییر نمی‌کند. |
| **سقف هزینه** | هر کلید سقف بودجهٔ ماهانه، محدودیت تعداد درخواست در دقیقه و فهرست مدل‌های مجاز خودش را دارد. موجودی پیش از ارسال هر درخواست بررسی می‌شود، پس اتمام موجودی باعث توقف درخواست‌ها می‌شود و بدهی ایجاد نمی‌کند. |
| **حریم خصوصی** | محتوای درخواست‌ها و پاسخ‌ها ذخیره نمی‌شود. فقط نام مدل، تعداد توکن، هزینه و زمان ثبت می‌شود که صورتحساب و گزارش مصرف از همان ساخته می‌شود. |

## مسیرها

| متد | مسیر | احراز هویت | پاسخ |
| --- | --- | --- | --- |
| `GET` | `/v1/models` | اختیاری | فهرست مدل‌ها. بدون کلید همهٔ مدل‌ها، با کلید فقط مدل‌های مجاز همان کلید. |
| `POST` | `/v1/chat/completions` | لازم | پاسخ با شکل OpenAI، با پشتیبانی از جریان. |
| `POST` | `/v1/messages` | لازم | پاسخ با شکل Anthropic، با پشتیبانی از جریان. |
| `GET` | `/v1/credits` | لازم | موجودی، مبلغ رزرو‌شده و قابل استفاده، سقف درخواست، بودجهٔ ماهانه و مدل‌های مجاز. |
| `GET` | `/v1/me` | لازم | همان پاسخ `/v1/credits`. |

بقیهٔ مسیرهای `/v1` بدون تغییر به سرویس بالادستی فرستاده می‌شوند، پس مسیر تازهٔ
بالادستی از همان روز کار می‌کند.

کلید را می‌توانید با هدر `Authorization: Bearer …` یا `x-api-key` بفرستید؛ هر
کدام که کتابخانهٔ شما از قبل می‌فرستد.

## مدل‌ها

صدها مدل، با قیمت ورودی و خروجی هر یک میلیون توکن به تومان، در
[kilidify.com/pricing](https://kilidify.com/pricing). شناسهٔ مدل‌ها همان شناسهٔ
بالادستی است، پس کدی که برای دروازهٔ دیگری نوشته شده معمولاً تغییری لازم ندارد:

```
anthropic/claude-opus-5.5        openai/gpt-5-nano
anthropic/claude-sonnet-5.5      google/gemini-4-argon
anthropic/claude-haiku-5.5       deepseek/deepseek-v4-flash
z-ai/glm-5.3-flash               qwen/qwen3.7-flash
```

پسوند `:batch` ردهٔ دسته‌ای بالادستی را انتخاب می‌کند، اگر برای آن مدل وجود
داشته باشد.

`kilidify/auto` برای هر نقش، مدلی را از نقشهٔ تنظیم‌شدهٔ همان کلید انتخاب می‌کند
و تنها به کلیدهایی پیشنهاد می‌شود که چنین نقشه‌ای دارند. توضیح در
[`docs/models.md`](docs/models.md).

## خطاها

خطاهای کلیدیفای یک `code` ماشین‌خوان و یک پیام فارسی در `message_fa` همراه پیام
انگلیسی دارند، تا همان پاسخ را بتوان بدون ترجمهٔ دوباره به کاربر فارسی‌زبان نشان
داد. خطاهای خود سرویس بالادستی بدون بازنویسی عبور داده می‌شوند.

```json
{
  "error": {
    "code": "insufficient_balance",
    "message": "Insufficient balance. Top up your wallet to continue.",
    "message_fa": "موجودی کیف پول شما کافی نیست. لطفاً حساب خود را شارژ کنید.",
    "type": "insufficient_quota"
  }
}
```

فهرست کامل کدها با وضعیت و راه‌حل: [`docs/errors.md`](docs/errors.md).

## ابزارها

- **[`@kilidify/claude`](https://www.npmjs.com/package/@kilidify/claude)** برای
  اجرای Claude Code و سرور MCP.
- **افزونهٔ VS Code** از [kilidify.com/apps](https://kilidify.com/apps).
- **بات تلگرام** برای گفتگو با هر مدلی از کاتالوگ، از داخل تلگرام و با هزینه از
  همان کیف پول. اتصال آن از پنل انجام می‌شود. یک نکته پیش از استفاده: بات‌های
  تلگرام رمزنگاری سرتاسری ندارند، پس پیام‌ها به‌صورت متن ساده روی سرورهای تلگرام
  می‌مانند. خود بات این را در `/start` می‌گوید.
